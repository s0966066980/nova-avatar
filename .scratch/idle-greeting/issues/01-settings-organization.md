# 集中閒置招呼設定並按用途整理設定頁

Type: task
Status: resolved

使用者找不到 AI 招呼 Prompt，要求全部招呼設定放在獨立頁，不跨頁設定；排版頁應移除與視覺排版無關的設定。

## 重現

`cd web && node --test tests/settings-organization.test.js` 在修正前失敗：側欄沒有可直接找到的「閒置招呼」入口。

## 原因與修正

原入口藏在角色編輯器，AI Prompt 還受下拉選單控制；開關與間隔分散到舞台設定。新增獨立招呼頁，集中內容、Prompt、字數、開關、間隔、預覽、試播、狀態與一個儲存／套用入口。套用失敗保留草稿，支援同頁重試。

訪客清場與 VAD 移到「訪客互動」，排版頁保留背景／字幕／看板／按鈕的視覺設定。儲存只提交目前頁面，完成後留在原處。專用招呼套用 API 保留其他尚未套用的角色身分／模型草稿，不重新載入人物，也不打斷已開始的招呼播放。

## 驗證

前端操作測試涵蓋完整招呼設定頁與設定面板導覽。`npm test` 114 項通過，Lint、Build 通過；後端 661 passed、3 skipped，整合與授權稽核通過。此環境未提供可操作的瀏覽器介面，未宣稱已完成實機試播。
