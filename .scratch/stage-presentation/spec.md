# 同步控制台與數位人舞台的目前問答

Status: resolved

控制台測試必須可直接驗證數位人舞台的畫面；訪客模式下，控制台也須看到舞台目前的問答。保留既有模式切換與每個來源的對話記憶。

## 驗收

- 控制台測試：控制台發問，兩端呈現同一個來源的語音、嘴型影格、提問、已播字幕與看板。
- 訪客模式：舞台收音，控制台同步觀看目前問答，不能取得輸入權。
- 開啟舞台不覆蓋管理者已明確選定的控制台測試模式。
- 新開或重連的頁面補齊目前一輪的問答與看板；未播的生成預覽不作為展示快照。
- 切換來源、角色轉場、清場及插話取消後，舊字幕、看板或媒體不能漏播；切換後 RTP 時間戳維持遞增，保留影音來源原有的時間差。
- 觀看端看板顯示收據回到實際產生回答的工作階段，重複收據不重複提交。
- 慢速觀看端不延後輸入端語音；關閉任一頁不關閉另一頁，最後一頁關閉時釋放分送工作與來源參照。

驗證與原因見[實作議題](issues/01-share-active-presentation.md)。
