# 瀏覽器影片合成與共用狀態機

Status: ready-for-agent
Type: task
Blocked by: 01, 02

建立控制台與獨立舞台共用的預錄呈現模組，串流播放無聲影片、
執行人物去背／背景合成並依接收語音切換，避免各頁自行實作狀態。

## 責任範圍

`web/src` 的呈現模組、`web/src/composables/useWebRTC.js`、
`web/src/App.vue`、`web/stage.html` 及場景預覽共用介面。

## 驗收

- 等待回答與使用者說話時循環待機；有效回覆出聲時改播說話。
- 靜音超過 300 ms 回待機；兩種影片之間約 100 ms 人物淡接，
  舞台背景不隨人物淡接，不延遲語音或等待影片播完。
- 綠幕／髮絲邊緣／溢色有實際預覽；支援目前舞台背景功能。
- 輪次取消／斷線取消排定事件，不重新啟動舊說話影片。
- 預載候選以避免黑畫面，解碼／快取有界，不展開整支原尺寸影片。
- 素材或合成失敗保留可用待機／預覽與語音，顯示原因；沒有
  隱藏 MuseTalk 回退。循環接縫不自動修補，提供預覽檢查。

## 驗證

測試具有時間資訊的狀態轉移、失效事件、快速插話與解碼失敗；
在兩個真實可見視窗檢查影片循環、背景切換、聲音與人物淡接。
