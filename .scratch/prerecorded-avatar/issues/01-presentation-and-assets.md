# 呈現方式與角色素材契約

Status: ready-for-agent
Type: task

同一角色新增獨立於原屬引擎的呈現方式與待機／說話素材配對，避免
把改用預錄誤當成建立或切換另一位角色。依 [spec.md](../spec.md)
實作每角色持久化、候選版本驗證、套用與上一版還原。

## 責任範圍

`src/config/schema.py`、`src/config/overrides.py`、`src/avatars/catalog.py`、
`src/server/runtime_settings.py` 與素材管理／設定路由。素材管理新增
模組須獨立於會刪除整個角色目錄的既有 builder overwrite 流程。

## 驗收

- 上傳同尺寸 MP4，移除原音、正規化 25 fps，保留原始角色與其他素材。
- 缺件、尺寸不合或解碼失敗有明確原因，未成功套用不修改目前配對。
- 逐角色保存方式與素材版本，重啟後恢復；既有角色預設 MuseTalk。
- 變更模式或使用中素材須所有會話斷線，有活躍會話時拒絕變更。
- 套用採原子更新，可還原上一版；失敗不刪除任何已使用素材。
- 對外只公開可用素材的受控 URL 與 metadata，不公開任意本機路徑。

## 驗證

擴充角色與 runtime settings 測試，涵蓋角色往返、重啟、原子更新
失敗、缺件、活躍會話與版本還原。用實際 MP4 驗證尺寸、25 fps
與無音軌，不只比對 metadata 宣告。
