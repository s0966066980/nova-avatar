# 瀏覽器對話錄影與 MP4 匯出

Status: ready-for-agent
Type: task
Blocked by: 02, 03

預錄呈現將合成人物／背景與該頁面的回答音訊一起錄製，維持
MP4 匯出。這個輸出與五秒綠幕說話素材是不同責任。

## 責任範圍

`web/src` 的錄影模組與 `web/src/App.vue` 的錄影操作；後端
新增受控上傳／非即時轉檔／下載工作介面，保持既有 MuseTalk 錄影。

## 驗收

- 擷取合成場景與該會話回答音軌，不混入麥克風、DOM 字幕或看板。
- 實際檢查瀏覽器 MIME 支援；不能直接錄 MP4 時保留原始錄影
  後背景轉檔，顯示進度，成功才提供 MP4。
- 停止／轉檔失敗保留可取得原檔供下載或重試，不虛報成功。
- 錄影頁面須保持開啟且在前景；失去前景時結束並保存已錄部分。
- 停止／斷線清理 capture tracks 與暫存，不關閉使用者麥克風權限。
- 轉檔保留影格與音訊時間軸，不加速、截短或掩蓋已發生的卡頓。

## 驗證

真實瀏覽器錄含待機、說話、背景切換和插話的影片；檢查 MP4
軌道、A/V 時長與內容。涵蓋支援偵測、轉檔失敗、失焦與斷線。
