# 控制台設定與素材操作

Status: ready-for-agent
Type: task
Blocked by: 01, 03, 04, 05

控制台提供同角色呈現方式選擇、待機／說話上傳及預覽、文字輸入
製作五秒說話素材、明確套用／還原，以及可理解的錯誤與工作進度。

## 責任範圍

`web/src/components/SettingsPanel.vue`、
`web/src/composables/useRuntimeSettings.js`、`web/src/App.vue` 與
必要的共用元件。使用 Nova Avatar 品牌與 CONTEXT.md 領域術語。

## 驗收

- 呈現方式與角色原屬引擎分開顯示，不讓角色選擇重置已記住的方式。
- 設定 snapshot、編輯 dirty state、套用請求和成功狀態一致。
- 素材兩個槽位有預覽、規格與缺件原因，可比較上一版並還原。
- 輸入文字製作顯示『五秒影片；製作可能超過五秒』，短文字可修正。
- 明確顯示連線／製作的互斥，不只斷控制台而留下舞台會話。
- 製作完成不自動替換，使用者按套用才提交；失敗不宣告套用成功。
- 保留輸出畫質與舞台背景設定，故障／未達標可手動調整。
- 錄影顯示前景要求、停止／轉檔進度與最終下載狀態。

## 驗證

覆蓋缺件、dirty state、角色往返、活躍舞台、製作取消、預覽與
套用失敗。實際操作窄／寬視窗，確認可讀狀態與鍵盤操作。
