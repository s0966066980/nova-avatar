# 五秒說話素材製作工作

Status: ready-for-agent
Type: task
Blocked by: 01, 02

輸入管理者指定文字，以 TTS 驅動 MuseTalk 離線製作目前角色的
五秒完整品質說話素材，不經 LLM 或正式對話歷史。

## 責任範圍

新增素材製作 service／job／routes，重用 TTS factory、MuseTalk
特徵、UNet／完整 VAE 與嘴型貼回；GPU 工作鎖參考
`src/server/import_jobs.py`。保留所有適用上游 attribution／license。

## 驗收

- 所有會話斷線後單工執行，顯示進度、成功／失敗與取消狀態。
- 從首段有效 PCM 開始取五秒；不足提示加長，超長取前五秒。
- 輸出 125 影格、25 fps、固定五秒、原角色綠幕、無音軌，
  不加入場景或額外字幕，不繼承即時輸出限高／產幀卡頓。
- 明確選用完整品質 VAE；模型不可用時報錯，不能換成輕量版。
- 製作耗時可以超過五秒；只在製作期間使用嘴型資源，工作結束
  或取消／失敗後清理並釋放，不改目前呈現方式。
- 產物先預覽／下載，明確套用後才替換說話素材；可還原上一版。
- 中斷／重啟清楚標記工作失效並處理暫存，已用素材保持完整。
- 缺少來源或可用 MuseTalk 素材時禁用製作並說明原因。

## 驗證

以實際文字與角色製作檢查影格數、時長、解析度、綠幕、原音
移除及完整 VAE 路徑；涵蓋短文字、取消、GPU 失敗與套用失敗。
監測資源釋放，不能僅用合成 API 返回成功視為影片完成。
