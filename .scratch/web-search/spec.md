# 網頁搜尋輔助回答

Status: 已確認並實作，驗證結果見 validation.md

## 目的與範圍

讓 Nova Avatar 目前的本機回答模型使用公開網頁資料，維持既有角色、語音、看板與輪次隔離。採後端控制的有上限搜尋流程，第一版不引入反覆自主工具呼叫、登入網站或瀏覽器操作。設計依據見 [ADR 0024](../../docs/adr/0024-bounded-web-search-before-answer.md)。

## 已確認行為

- 各數位人設定檔獨立啟用，預設關閉；啟用後由模型判斷是否需要搜尋並產生必要關鍵字。
- 先以 DDGS 的 DuckDuckGo 搜尋，沒有可用結果時嘗試 Brave。一次搜尋作業包含此有限備援，不因備援而重設預算或增加結果上限。
- 每輪最多五筆結果、讀取最多三頁；搜尋與讀頁合計最多八秒。模型判斷、回答生成與語音合成不包含在八秒內，量測時須分開呈現。
- 外送只包含必要搜尋關鍵字及追問所需主題、日期與地點，不自動外送附件原文、內部檢索片段或完整對話。
- 等待時顯示搜尋狀態，取得資料或預算用盡後才形成正式回答；插話、斷線、重置後不交付舊輪次結果。
- 控制台與舞台各自顯示可展開來源，包含標題、連結與搜尋摘要／已讀取網頁狀態；數位人不朗讀網址。來源由後端結果產生，不接受模型捏造來源。
- 附件問題忠實依附件；最新公開資訊優先採可確認日期的官方網頁；天氣沿用既有專用工具。衝突時說明差異及依據。
- 部分資料足夠時可回答；只有摘要時揭露未讀全文。完全失敗時告知未能查證最新資訊，一般背景知識須與查證結果分開。
- 同場、同角色、同主題五分鐘內可重用；明確要求重新查詢或最新資訊則重新搜尋。對話重置即清除，角色間及訪客間不共用。
- 預設可讀搜尋結果中的公開網站，管理者可限制網域。本機、內網、非公開位址與重新導向後的受限目標均阻擋；網頁文字不能改寫系統或角色指令。

## 實作接縫與約束

- `src/server/voice_session.py` 的 `_answer_inputs` 與 `_stream_answer` 已有本輪參考資料接縫；搜尋資料需保留獨立來源型別，不冒充 RAGFlow 片段或正式引文。
- `src/llm/engines/openai.py` 目前只取回答文字；搜尋判斷與關鍵字輸出需有獨立受驗證的結構，不能混入既有口語／看板回覆協定。
- 現行 ADR 0022 允許路由未定案前推測回答。外部搜尋須等目的角色及其搜尋設定確定，不能因推測生成而從未獲允許的角色向外傳送查詢。未啟用搜尋的普通輪次維持原流程。
- 查詢規劃使用必要的公開問題背景，不直接重用附件分析後或包含內部 RAG 內容的完整回答輸入。
- DDGS、讀頁、取消與結果交付均受輪次識別與 generation 檢查保護。阻塞工作離開 event loop；外部請求設 timeout、資料量上限及共享截止時間。
- 讀頁依據後端保存的搜尋結果識別，不新增接受任意檔案路徑或任意 URL 的訪客 API。網址連結經安全協定驗證，網頁內容經文字擷取及輸出跳脫。
- 不複製 Unsloth Studio 的 AGPL 程式碼；依功能需求自行實作，新增依賴前確認 Python 相容性、固定版本與授權 notices。
- 新增或修改設定／測試 API 前依 ADR 0021 分類存取權限；沿用各場獨立的狀態與閒置重置。

## 驗收條件

1. 關閉搜尋的角色及不需搜尋的問題不呼叫外部搜尋；角色交接不繞過設定。
2. DuckDuckGo 有結果時不呼叫 Brave；無可用結果時才備援，最多五筆結果與三個讀頁，合計截止時間不重設。
3. 外送請求不包含附件內容、內部知識庫片段或完整歷史；追問僅使用必要公開背景。
4. 本機、內網、DNS 解析與重新導向限制均有回歸案例；網頁中的指令不改寫角色規則。
5. 成功、零結果、限流、逾時、部分讀頁失敗及只有摘要均呈現正確狀態，不假稱最新資訊已查證。
6. 插話、斷線、角色變動與重置時，舊輪次搜尋結果、來源與待播回答不滲入新輪次。
7. 五分鐘內符合條件的追問重用原資料；過期或要求重新查詢時再次搜尋；另一場、角色或重置後不能取得舊資料。
8. 舞台與控制台來源清單各自正確呈現，網址不進語音，標題和連結不由模型自行捏造。
9. 使用真實本機模型驗證中英文、一般寒暄、最新資訊、天氣、附件追問與知識庫衝突；分別量測搜尋規劃、外部查詢／讀頁及感知首音延遲，不將八秒預算當作端到端保證。
10. 實作完成後執行 CI 對應的 lint、型別、品牌授權稽核、前後端測試與建置，記錄實際服務驗證範圍。
