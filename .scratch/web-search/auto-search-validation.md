# 公開資訊查詢與舊拒答修正

2026-11-03。使用者回報「周杰倫現在幾歲」拒答，明確要求搜尋後仍說沒有即時個資，雖然介面已顯示五筆網頁來源。使用者另同意調整主數位人對公開出生日期、年齡及一般公開日期／時間／版本資訊的限制；私人聯絡方式與非公開個資仍受保護。

## 診斷

- 本機保存的主角色搜尋已開啟；天氣角色未開啟一般搜尋。
- 不加「搜尋」的七個代表問題中，公開具體資訊問題會觸發搜尋，寒暄及一般穩定常識不搜尋。此次沒有找到能穩定證明所有普通問題都不搜尋的案例，未因此改成每題強制上網。
- 新場次中使用目前角色身分、規則及 Gemma 4 E2B，兩個原句都能搜尋並回答；加入使用者提供的舊拒答作為已提交歷史後，重現「五筆來源已取得，卻仍表示沒有即時年齡資料」的症狀。
- 單純放寬角色限制仍不足以消除舊拒答。單次模型輸出也曾出現錯誤計算／年份，不能把生成成功視為任意年齡問題都可靠。

## 修改

1. 透過修訂版本檢查的 ProfileStore 更新主角色限制，允許有可靠公開來源的公眾人物出生日期、年齡與一般公開日期／時間／版本資訊，保留非公開個資保護；其他角色與限制條款維持原值。設定變更範圍見 [public-information-policy-change.json](public-information-policy-change.json)。實際設定在本機 gitignored 的 `config/avatar_profiles.yaml`。
2. 只有本輪實際取得網頁來源時，才在本次 LLM 請求加入來源可用狀態、查詢日期及重新核對舊拒答的提醒。明確要求保留角色與非公開個資限制，沒有把網頁內容升為指令。
3. 以 RequestQuestion 保存原始問題；adapter 只在發送請求時附加提醒。已提交的問答、附件影像 parts 與原始問題不被重寫，提醒不會寫進對話歷史，也不送往搜尋引擎。
