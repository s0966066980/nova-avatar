Project map · 2026.09

讓 AI 回覆，真的開口說話。

這是一套本機優先的即時數字人系統：瀏覽器送出語音，後端負責判斷發話、理解內容、產生回覆、合成聲音，再把有嘴型的影音即時傳回來。

先看一次完整流程 閱讀 README 查看目前完成度
前端Vue 3 + Vite
後端Python + aiohttp
即時傳輸WebRTC 雙向影音
主要語言繁體中文介面

What it solves

它不是單一模型，而是一條可替換的對話生產線

每個環節都有統一介面與工廠，可以換掉辨識、LLM、聲音或數字人，而不必重寫整個產品。

01

把語音變成一個輪次

WebRTC 持續送麥克風音軌，Silero 在伺服器判斷「開始說」與「說完」，避免前後端各切一次。

02

把模型能力做成設定

使用者可直接選擇 LLM、Prompt、回覆字數、STT、TTS、聲音與 Avatar，並在套用前完成驗證。

03

把回覆變成即時影音

TTS 音訊被切成 20 ms 幀，數字人引擎依音訊驅動嘴型，再透過 WebRTC 回到瀏覽器。

End-to-end flow

一次語音對話，會經過八個步驟

伺服器是唯一輪次編排者；前端呈現狀態並承載影音，不重送錄音，也不自行猜測數字人是否正在說話。

建立 WebRTC

瀏覽器協商音訊、影像與事件通道。

傳送麥克風

可收音時持續送出上行音軌。

Silero 切段

在後端判斷一段完整發話。

STT 辨識

Whisper 或 FunASR 產生文字。

LLM 回覆

Ollama 或 llama.cpp 產生 chunk，串流模式依語意邊界形成可播片段。

TTS 合成

片段經有界背壓依序產生音訊，所有資料保留輪次 envelope。

Avatar 渲染

模型依聲音驅動嘴型；MuseTalk 在段落邊界只平滑嘴部 ROI。

回傳影音

前端播放並依發話狀態暫停或恢復收音。

隱私邊界 麥克風音訊預設只存在短生命週期的記憶體緩衝；完成、取消或斷線後即清除。只有使用者明確啟動錄製功能才會保存會話影音。

Architecture layers

從畫面到模型，共六個責任層

看資料夾就能定位問題：畫面問題先看 Web、輪次問題看 Server、模型問題則回到各自引擎層。

互動層
web/src/

Vue 畫面、設定面板、字幕、錄音控制、i18n 與 WebRTC composables。

會話層
src/server/

aiohttp API、WebRTC 協商、事件推送、單一對話輪次與插話取消。

理解層
src/vad/ · src/asr/

Silero 判斷發話邊界，再由 STT 將完整發話轉成文字。

回覆層
src/llm/ · src/server/reply_streaming/

Prompt、交易式歷史、模型 chunk、語意切片、媒體背壓與輪次隔離。

聲音／渲染層
src/tts/ · src/avatars/

語音合成佇列、固定音訊幀、嘴型同步與數字人畫面生成。

設定層
src/config/ · runtime_settings.py

設定 schema、試聽、執行時套用、資源切換守門與 YAML 持久化。

Streaming reality

可靠回覆語音串流已完成主力組合驗證

串流模式已把 LLM chunk、語意切片、TTS、MuseTalk 與 WebRTC 串成同一個可取消輪次；舊有模式仍保留作為跨引擎回退。

已完成

文字與語音共用串流管線

  • LLM 回覆以 chunk 方式接收。
  • 語意切片器支援強／弱標點與長無標點回答。
  • 可播片段立即排入有界 TTS／Avatar 管線。
  • generation fence、播放提交、字幕與 history 只接受有效且已播資料。
限制

正式保證範圍

  • 50 回合 SLO 目前涵蓋 Edge TTS＋MuseTalk、單一會話。
  • reply_streaming.enabled 預設仍為 false。
  • 其他 TTS／Avatar 保持相容，但尚未逐一取得同等 SLO。
  • direct PCM 實驗路徑關閉，正式路徑使用單一音訊 producer。
舊有模式與串流模式的 TTS 時機 串流模式在可播語意片段形成後立即送入 TTS 與數字人；舊有模式等 LLM 全文結束後一次合成。兩者都不是引擎邊推理邊吐波形的增量 TTS。

Quick start

最短啟動路徑

先準備 Python、uv、Node.js、FFmpeg 與對應模型；GPU 是多數數字人與本機語音引擎的建議環境。

啟動前檢查

  1. Python 3.10／3.11 與 uv 可用。
  2. Node.js／npm 已安裝。
  3. 所選 Avatar 的權重與角色素材齊全。
  4. 需要麥克風時已建立HTTPS 憑證。
# 1. 安裝一套入門環境
bash scripts/setup-env.sh wav2lip

# 2. 建立本機 HTTPS 憑證
bash scripts/create_ssl_certs.sh

# 3. 同時啟動前後端
bash scripts/start-all.sh config/config.yaml

# 4. 開啟前端
https://localhost:3000
