# 預錄數位人

在控制台的「設定 → 數位人與畫質 → 數位人呈現方式」選擇
MuseTalk 即時嘴型或預錄呈現。每位角色會分別保存選擇，重新啟動
`bash scripts/start-jetson.sh` 後沿用。既有角色預設 MuseTalk。

預錄呈現使用待機與說話兩支循環影片；回覆語音有聲時播放說話動作，
靜音超過 300 ms、回答結束或中斷後回待機。嘴型是通用動作，
沒有逐字對齊發音；LLM、聲音、語音輸入與對話歷史仍使用目前設定。

## 準備與套用

1. 控制台與舞台都先斷線。
2. 在目前角色上傳「待機影片」與「說話影片」。第一版接受 MP4，
   每支最多 100 MB、十分鐘、3840×2160 像素；兩支必須同尺寸，
   並使用相同人物、構圖與綠幕。
3. 等待準備完成。系統移除原音並統一為 25 fps。先在素材播放器
   檢查循環接縫，再按各自的「套用為待機／說話影片」。
4. 用「預覽待機與背景」與「預覽說話與背景」確認去背與構圖。
   然後選「預錄呈現」，按「套用呈現方式」。預設會結束目前對話並
   自動重新連線控制台與舞台；也可取消自動重連，先手動斷線再套用。

候選素材完成後不會自動替換使用中的影片。套用會保留上一版，
可在所有會話斷線後按「還原上一版」。原本 MuseTalk 角色素材保留。
若兩支影片未備齊、尺寸不同或檔案遺失，畫面會提示原因，不能啟用。
播放出錯會顯示錯誤並保留待機或預覽圖與語音，不會暗中載入 MuseTalk。
首次連線先顯示待機，等接收端語音時鐘就緒才切換說話影片。
瀏覽器若暫時缺少播放時序資訊，會提示等待並維持待機，持續嘗試
校準；時鐘恢復後自動恢復說話切換與錄影，不必重新連線。

## 製作五秒說話影片

套用具有綠幕 MuseTalk 素材的角色，斷開所有會話，在「錄製 5 秒
說話素材」輸入朗讀文字，按「製作 5 秒說話影片」。製作只使用目前
的 TTS 與 MuseTalk，不會詢問 LLM，也不會寫入對話歷史。

系統從首段有效語音取五秒，以完整品質 VAE 產出 125 影格、25 fps、
無音軌且保留綠幕的影片。文字超過五秒只取前五秒；不足五秒會提示
加長，不會用待機補滿。五秒是影片長度，製作時間可能超過五秒；
Orin 實測一次約 68 秒，仍依角色、聲音與負載而異。

製作畫面有進度與取消，可關閉設定面板後再開啟查看同一工作。
完成、取消或失敗後會釋放製作資源、恢復目前呈現方式。完成後先
預覽或下載，再按「套用為說話影片」；待機影片須另行準備。

## 背景、錄影與畫質

舞台背景仍可選圖片、GIF 或循環影片。控制台與舞台共用背景、角色
和呈現方式，各自維持獨立對話。

預錄模式由瀏覽器解碼影片、去背、合成背景並錄影。開始錄影後，
該頁面須保持開啟且在前景；離開前景會停止並保存已錄部分。錄影
包含該端數位人、背景與回覆語音，不含麥克風、字幕或看板。
停止後由伺服器匯出 MP4；已有 H.264 的影片保留原影像，必要時只轉音軌。
匯出失敗可下載瀏覽器原始錄影，伺服器也保留收到的原始檔。

預錄畫質保留上傳影片的原始尺寸，不受 MuseTalk 輸出解析度、銳利度
或貼回參數影響；這些設定只在即時模式顯示並保留原值。若裝置無法
流暢解碼原始影片，請上傳較低解析度的兩支影片。效能取決於瀏覽器影片解碼與 WebGL
是否由 GPU 加速。目標裝置與十分鐘雙畫面結果見
[實測紀錄](../.scratch/prerecorded-avatar/validation/README.md)。

切換期間仍可讀取健康與設定資訊；相同模式不會重載模型。正常預錄
連線不會載入 MuseTalk；沒有麥克風上行時也不會準備 VAD/STT。
有麥克風時，VAD/STT 與連線協商平行準備，完成前不會開啟收音。
待機畫面先顯示，語音時鐘校準完成後才切換說話影片或允許錄影。
區網連線預設不依賴外部 STUN；跨網路部署需另行設定可達的 ICE 服務。

錄影與素材下載共用先取得影片再下載的流程，以避免自簽 HTTPS 下
直接網址下載被瀏覽器取消；HTTP 錯誤會顯示於操作介面。每個頁面
使用自己的連線識別，重新連線會釋放同頁舊會話，不會佔用另一種頁面
的名額。控制台與舞台各自保留對話與音訊；兩個畫面同時發聲時，
可使用瀏覽器的分頁靜音選擇要聽的畫面。

舞台已暫停收音時，自動重連會保留暫停選擇；麥克風準備完成後
也不會自動恢復收音。本次切換、啟動、下載與雙畫面回歸結果見
[操作修正驗證](../.scratch/prerecorded-avatar/fixes/README.md)。
