# 以數位人設定檔隔離角色設定與訪客記憶

為讓主數位人交接原問題後，由專門數位人以自己的身分回答，人物素材、身分與限制 Prompt、LLM、RAG 知識範圍、聲音及回覆規則改由各自的數位人設定檔保存，舞台背景仍由演播場景共用。對話記憶依訪客及角色隔離，切回某角色時接續該角色自己的記憶，訪客對話重置時清除各角色記憶；跨角色回答透過明確交接原問題銜接，以免共用完整歷史造成身分與知識範圍混用。

## Scope

- 此為 2026-10-16 設計訪談中已確認的取捨，功能尚未實作；詳細規格見[角色交接規格](../../.scratch/live-avatar-switch/spec.md)。
- 設定檔身分獨立於人物素材，同一人物素材可供多份設定檔引用；訪客記憶與知識範圍隨設定檔隔離。既有有效設定先保存為主角色設定檔。
- 主數位人的 LLM 依管理者可編輯的交接規則與專門角色介紹決定交接，語意不清楚時先詢問訪客；接手主題可設定，以天氣作為第一個驗收案例。
- 明確交接原問題與必要的已確認地點、日期等上下文；兩角色保留各自歷史。
- 主數位人的交接說明採可編輯固定文案；各方向的轉場設定獨立。
- 舞台與控制台都在專門角色作用中顯示返回按鈕。人工返回停止剩餘回答、保留已播內容及本訪客各角色記憶；閒置訪客對話重置則清各角色記憶並轉回主數位人。
- 角色就緒後才播交接說明；說明中可插話取消，轉場中暫停收音與重複切換。轉場開始清舞台字幕及看板，返回時保留記憶但不自動重顯示舊答案。
- 首版驗收以 `musetalk_angela` 為主角色、`musetalk_1` 為天氣角色，共用 Qwen3.5 9B；每份設定檔仍保存自己的模型選擇，不由這個驗收組合推論任意兩個模型都能同時駐留。
- 修訂 [ADR-0012](0012-editable-rules-for-single-llm.md) 的「服務共用規則／不採每角色規則」範圍；以自然語言規則指導回答、固定協定不開放編輯及輪次快照的決定繼續適用。
- 修訂 [ADR-0015](0015-console-owned-assistant-profile.md) 的全域助手設定範圍；控制台仍為身分設定的唯一管理介面。選擇既有設定檔與修改該設定檔的身分是不同操作，切換角色本身不清除該訪客已有的角色對話記憶。
- 設定檔保存目前設定，不包含版本歷程與還原功能，也不將訪客對話作為設定檔內容持久保存。

## Considered Options

- 所有角色共用助手身分、回覆規則與對話歷史：角色切換後容易沿用其他角色的身分、規則與上下文。
- 每次切換清除全部歷史：無法在返回主數位人或再次交給專門數位人時接續本訪客已進行的對話。
