# 由後端控制有上限的網頁搜尋，再交給目前模型回答

使用者已確認完整設計並要求開始實作。網頁搜尋是角色設定檔上的能力政策，與 ADR 0023 指定給組合成員的天氣等專用工具分開保存。

第一版由模型提出搜尋需求與關鍵字，後端控制搜尋、讀頁次數與等待預算，再將取得的參考資料交給目前的本機回答模型。沿用現有回答、語音輸出與輪次隔離流程；完整的反覆自主工具呼叫循環留待後續評估。相較直接引入通用 agent loop，此範圍可先驗證搜尋品質與數位人的等待體驗，並避免工具呼叫與現有口語／看板回覆協定互相干擾。

現有主回答 adapter 只處理文字串流，沒有通用工具循環；現有 RAG 檢索的 300 ms 預算也不能直接視為網頁搜尋的預算。本決策補充 ADR 0013 與 ADR 0022。

## 已確認範圍

- 管理者在各數位人設定檔獨立啟用，預設關閉；開啟後由模型按問題判斷是否需要搜尋。
- 第一版採 DDGS 免金鑰搜尋，先用 DuckDuckGo，沒有可用結果時再嘗試 Brave，兩者共用搜尋與讀頁預算；保留替換搜尋服務的介面。
- 只外送本輪必要搜尋關鍵字，以及追問所需的主題、日期與地點；不自動外送附件內容、內部知識庫片段或完整對話。
- 每輪一次搜尋、最多五筆結果、讀取最多三個頁面；搜尋與讀頁合計最多八秒。這是初始執行預算，不是從訪客停止說話到播出答案的總延遲保證。
- 等待時顯示「正在搜尋資料」；插話可取消，取得資料後才開始正式回答。
- 控制台與舞台各自顯示可展開的來源清單，包含標題與連結；來源資料由後端實際取得的結果產生，區分搜尋摘要與已讀取網頁。數位人口述重點，不朗讀網址。

## 資料、失敗與追問

- 詢問附件內容時忠實說明附件；最新公開資訊優先參考可確認日期的官方網頁；天氣沿用既有氣象工具。仍有衝突時說明來源與差異，不靜默合併。
- 有足夠資料即可回答並標示來源；只有搜尋摘要時說明未核對全文。完全失敗時明確告知；最新資訊不得以模型記憶補成已查證答案，一般背景知識可另行說明。
- 同場、同角色、同主題五分鐘內可重用搜尋資料；要求重新查詢或最新資料時再搜尋。資料隨該場對話重置清除，第一版不跨角色或訪客共用。
- 可讀取搜尋結果中的公開網站，管理者可選擇限制網域；阻擋本機與內網位址，重新導向也適用相同邊界。網頁內容一律是參考資料，不能改寫角色與系統指令。

實作與驗收規格見 網頁搜尋輔助回答。

## 2026-11-03：隔離 DDGS 相容請求

已確認並實作的修復沿用 DDGS 9.14.4 的搜尋與解析，將引擎實例／HTTP client 私有介面的依賴集中在 `services/llm/nova_llm/web_search/ddgs_adapter.py`。僅為本次 DuckDuckGo 實例設定穩定標頭，移除空分頁 token 與預設美國地域欄位，保留原始查詢及明確篩選。完整預設請求曾觸發驗證頁而被 DDGS 誤報為沒有結果；相容請求經實網已取得結果。

相較自行維護搜尋頁解析，此選擇縮小修復範圍，代價是升級 DDGS 前必須重驗私有介面；版本或引擎不相容就明確失敗，不改套件檔案或全域標頭，不退回任意引擎。限流與驗證頁仍是不可用，沒有新增驗證碼處理或重試放寬。原有角色、隱私與八秒預算保持適用。證據與驗收見修復規格。

## 2026-11-03：取得公開來源後重新評估舊拒答

實測重現已有網頁來源，模型卻沿用歷史「沒有即時個資」拒答的情況。使用者同意調整主角色公開資訊政策，並在本輪有來源時附加一次性的資料可用狀態與日期提醒，讓模型重新核對公開事實；角色限制與非公開個資保護仍具約束力。提醒只存在於模型請求，不能重寫原問題或進入已提交對話歷史，也不得送往搜尋引擎。這沿用既有輪次與檢索責任，不新增無界工具循環。驗證與限制見公開資訊查詢修正。

## 2026-11-03：整理證據與限制搜尋回答的重複輸出

實網重現生日問題混入人物生平、錯誤日期及循環複誦；問題跨越證據選取與串流輸出，不能靠替特定人物加答案修正。

新增有四秒上限的證據整理階段，沿用目前設定的 LLM 端點，以 JSON 選取詢問欄位及短引文。以查詢詞定位頁面中的相關視窗，避免只取導覽列；引文須能回查實際來源，不能丟失數字正負號或版本分節。比較題保留多項不同證據，相同引文合併；個別拼接錯誤的引文捨棄，全部不可驗證或整理逾時就明確告知，不把原始全文再交回模型。

單一短事實可直接使用驗證過的引文，避免第二次生成額外生平；需要計算、翻譯或比較時才由回答模型整合選定片段。角色限制提供給整理器，附件問題仍沿原有附件回答流程。來源與本輪提醒只進入一次性請求，不成為歷史使用者文字或系統規則；來源清單保留實際搜尋結果。

搜尋回答另在預覽、TTS 與已接受的回答文字之前攔截重複片段，超過口語預算時停止取用模型串流，以完整語句片段為界，不截斷日期或數值。這個保護只用於已有網頁證據的回答，不影響一般聊天。控制台與舞台顯示整理狀態，直接回答時也會清除等待狀態；取消與輪次隔離維持適用。

這不能保證小型模型的語意選取或每項網頁事實都正確；具體實測、重現方式與仍存在的限制見跨題型整理驗證。
