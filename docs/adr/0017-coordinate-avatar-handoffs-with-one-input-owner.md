# 以單一輸入來源協調共用角色交接

控制台與舞台共用作用中角色，但原本可以各自同時發問；保留此行為會讓兩個問題爭用全域角色，因此新增明確的訪客／控制台測試模式，同一時間只接受一個輸入來源，兩端保留媒體連線與各自的角色記憶。伺服器單獨編排交接、媒體時間與角色轉場；首版即時組合共用同一 MuseTalk 推理模型及同一 LLM，預載兩角色素材，以免任意本機模型換載破壞即時切換契約。

此為使用者已確認的首版限制；不同模型仍可保存於設定檔，不相容的組合在啟用前明確拒絕，不能暗中重連或換載。細節與驗收目標見[完整規格](../../.scratch/live-avatar-switch/spec.md)。

## 2026-10-22：共用目前對話的展示

輸入權與展示來源分開處理。控制台測試時，由控制台接收提問，控制台與舞台共同播放該次測試的聲音、人物影格、提問、已播字幕與看板；訪客模式則由舞台收音，控制台同步觀看舞台目前的問答。兩端共用輸入端的實際播放內容，不重複呼叫模型或合成語音，各自的對話記憶仍隨原有工作階段保存。

伺服器統一分送影音與事件，保留來源的輪次、取消代數與角色媒體隔離。切換來源時清除展示緩衝並補齊目的來源目前一輪的已播內容；後開或重連的頁面可直接看到目前問答。展示頁較慢不阻塞輸入端語音，輸入端仍保留音訊背壓。明確選擇控制台測試後，開啟舞台不自動切回訪客模式。
