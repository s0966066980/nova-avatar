# 以單一輸入來源協調共用角色交接

控制台與舞台共用作用中角色，但原本可以各自同時發問；保留此行為會讓兩個問題爭用全域角色，因此新增明確的訪客／控制台測試模式，同一時間只接受一個輸入來源，兩端保留媒體連線與各自的角色記憶。伺服器單獨編排交接、媒體時間與角色轉場；首版即時組合共用同一 MuseTalk 推理模型及同一 LLM，預載兩角色素材，以免任意本機模型換載破壞即時切換契約。

此為使用者已確認的首版限制；不同模型仍可保存於設定檔，不相容的組合在啟用前明確拒絕，不能暗中重連或換載。細節與驗收目標見[完整規格](../../.scratch/live-avatar-switch/spec.md)。
