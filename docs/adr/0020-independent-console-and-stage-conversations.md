# 讓控制台與舞台各自持有對話與角色

使用者於 2026-10-29 接受移除訪客／控制台測試模式，保留 PC 角色交接、
天氣、雙語與附件，兩端各自擁有角色、記憶、語系、收音與影音展示。
這取代 [ADR-0017](0017-coordinate-avatar-handoffs-with-one-input-owner.md)
的單一輸入來源、共用作用中角色與同步展示，以及
[ADR-0019](0019-keep-conversation-state-across-role-handoffs.md)
對那些限制的沿用；角色身分與每角色記憶隔離繼續適用。

改用各場對話編排角色交接，避免一端的停止、返回、切換、重置與斷線
中斷另一端。閒置招呼及訪客自動重置僅屬於舞台；設定檔、模型與素材
仍可共用，但儲存設定不改動舞台進行中的對話，新設定於下一場採用。
此取捨放棄控制台問答直接同步投影舞台的能力，換取兩端正常且獨立的
互動；共用硬體的運算負載並不因此獲得獨立資源保證。

使用者已接受 Q1–Q3 並確認完整方案。新舞台對話的起點為完整自動重置或重新連線；手動清空、角色交接與畫面清除不改採新預設。需重載的共用資源標記待套用，兩端斷線後再更新，不自動中斷會話。
詳見[規格](../../.scratch/independent-console-stage/spec.md)。

## 2026-10-29：控制台也採用獨立自動清場

使用者回報控制台在天氣助手時不會清空或自動返回，並明確確認
「是，控制台也自動清場並返回」。因此修訂本 ADR 原先「訪客自動重置
僅屬於舞台」的範圍：控制台與舞台各自使用既有的清畫面／完整重置
秒數，預設 15／60 秒，完整重置清本場所有角色記憶、附件及草稿並返回
主數位人，由新一場採用新預設。閒置招呼仍僅屬舞台，兩場的活動與
清場計時繼續隔離。詳見[控制台清場修正](../../.scratch/console-idle-reset/spec.md)。
