# 以可編輯回覆規則指導單一 LLM

使用者需要從控制台修改 LLM 何時使用看板及如何回答，因此回覆規則採自然語言指令，由同一個 LLM 理解並生成內容。控制台分為看板啟用、口語回答及看板內容三區；規則由目前服務共用，套用後下一輪生效並在重啟後保留，已開始的輪次持有原規則。

此為已確認且已完成程式實作與自動驗證的設計決定。

2026-10-16：[ADR-0016](0016-isolate-avatar-profiles-and-visitor-memory.md)
已接受以數位人設定檔各自保存規則的新設計，修訂下列服務共用與不採每角色規則的範圍；新功能仍在設計訪談中，尚未實作。

## Considered Options

- 硬編碼關鍵字計分、灰區再分類：使用者已修正此方向。它無法讓控制台中的自然語言 Rule 成為回答行為的主要設定來源，也增加分類與生成模式不一致的責任。
- 開放編輯包含協定標記的完整提示詞：不採用。內容規則需要可調整，但資料格式應維持可解析，不應因使用者修改文案而讓看板內容進入語音。
- 每個數字人獨立保存規則：目前不採用。第一版採服務共用規則，讓設定作用範圍清楚且一致。

## Consequences

- Rule 作為預設內容原則，允許使用者本輪明確調整呈現方式；功能關閉與固定輸出格式仍由系統約束。
- 草稿與生效規則分開；儲存成功才發布新版本，進行中的輪次不受中途修改影響。
- 規劃由一次回答生成完成模式與內容，後端根據完整合法的模式輸出分流；既有 classifier 路徑需要調整，不能因同樣使用主模型就視為已滿足新設計。
- 已播語音與已顯示看板仍遵守各自的提交與輪次隔離契約。模型遵守提示詞不能替代程式驗證。
