# 當次角色組合改為一主多專、任意角色直接交接

ADR 0016 以「主數位人＋一位專門數位人」為前提：一份共用的交接規則、只會判斷「交給專門數位人或交回主數位人」的路由、天氣地點放在交接設定裡。現場將陸續加入客服、交通、展覽等角色，訪客也可能在任何角色前提出任何主題，例如在客服小幫手面前問天氣。

改為一位主數位人加上最多五位啟用中的專門數位人。每位成員（包含主數位人）在組合中有自己的專長介紹、交接規則、交接說明與工具，各自保存、互不影響；未啟用的成員保留設定。每一輪由路由在所有啟用成員中選出回答者，任一位可直接交給任一位，不必先回到主數位人；延續上一題的追問留在目前角色，混合主題先向訪客確認。主數位人只負責開場與兜底。轉場改為一份預設加上任意方向的個別覆寫。所有成員共用同一套語音合成引擎與回答模型服務。

## 取捨

- 路由每輪要在最多六位角色中選擇，Gemma 4 E2B 選錯的機會比二選一高；以上限五位、每位角色擴充固定路由題組，並保留關鍵字初篩（天氣工具同時只限一位成員持有）來控制。
- 交接說明改成「每位目的角色一句」，不再區分交出與交回；換來任何方向都不需要額外文案，代價是無法為特定來源寫專屬說法。
- 交接設定存在組合的成員上而非數位人設定檔，讓同一份設定檔在不同組合中可以有不同規則；目前只有一個組合。
- 捨棄的方案：所有交接一律經過主數位人（多一次交接說明與等待）；多組具名組合（介面與資料複雜度高，需要時再加）。

細節與驗收見角色組合規格。
