# 各場舞台對話獨立擁有語系，控制台保存新對話預設

不同舞台需要同時使用中文或英文，因此舞台語系由各場對話獨立擁有，一次同步舞台介面、語音辨識、回覆文字及回覆語音；控制台保存新對話預設及中英文各自的預設聲音。舞台切換語系立即停止目前回答，依既有提交契約保留已播回覆、已顯示看板及先前對話，不翻譯舊內容，也不改變其他場對話。

此決策補充 [ADR 0015](0015-console-owned-assistant-profile.md)：助手身分與 Prompt 仍由控制台集中管理，但舞台目前使用的語系不能只由服務共用的 `assistant_profile.output_locale` 決定。直接重用現有全域 profile 或語音設定套用流程，會清空其他場對話或要求全部斷線，無法滿足已確認的隔離與即時切換需求。

此決策已於 2026-10-27 實作。控制台可選自己的對話或某個已連線舞台操作，新對話預設另外保存；切換失敗維持原語系，同頁斷線重連沿用所選語系，新 session 導致記憶清空時明確提示。即時收音使用各場獨立的 Silero 模型，避免跨場 RNN 狀態污染與並行推論崩潰。完整行為與驗收案例見[功能規格](../../.scratch/stage-language/spec.md)。
