# Edge 只作為 Matcha 訓練的測試用老師

管理者決定在控制台提供以 Edge 朗讀聲音合成訓練語料的功能，作為訓練流程的測試用老師；這修訂 ADR 0025 中「訓練流程不使用 Edge 當老師」的部分。Microsoft Services Agreement §14(s)(iv) 禁止以 AI 服務的資料訓練任何 AI，不限商用，Edge 朗讀端點是否在適用範圍內仍未確認，所以這個功能只在下列限制內開放：

- 只在控制台、管理者登入後可用，介面顯示該條文，勾選確認後才能開始。
- 以 Edge 語料訓練出的聲線模型一律標示 Development only，不提供匯出，也不進入散佈流程。
- 語料經過任何處理，來源都不改變，標示不能降級。
- 自己錄的與有書面授權的語料不受 Edge 限制，但因底模訓練資料來源不明，產出仍標示 Research / Non-commercial。

相較完全排除 Edge，這讓管理者能在沒有授權錄音時實際測試整條訓練流程與介面；代價是產品內多了一個有條款風險的功能，所以靠標示、確認與不匯出來限縮，而不是靠系統阻擋。聲線變造與聲線轉換已由管理者取消開發，不在本決策範圍；若日後重啟，仍須遵守同一條標示規則。

規格見 [Matcha 訓練工作台](../../.scratch/matcha-training/spec.md)。
